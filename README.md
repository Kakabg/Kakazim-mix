# kakazim-mix (aposentado)

**Este bot não roda mais.** Desde 2026-10-07 os comandos do `!mix`
(`!mix`, `!play`, `!gc`, `!nick`, `!nome`) fazem parte do
[kakazim-bot](https://github.com/Kakabg/Kakazim-bot), na pasta `mix/`.

O serviço `Kakazim-mix` no Railway foi parado e desconectado deste
repositório. **Não religue:** os dois bots responderiam ao mesmo `!mix`.

Mudanças no `!mix` agora são feitas no kakazim-bot. Este repositório fica só
como histórico (inclui a migração `migrations/001-jogadores-para-perfis-global.js`).
